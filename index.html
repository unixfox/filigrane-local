Ajoutez un filigrane à n'importe quel document

L’ajout d’un filigrane sur vos documents est une bonne pratique : il limite la réutilisation frauduleuse de vos pièces justificatives. Certains organismes peuvent toutefois avoir besoin d’un document vierge (banques, services publics, etc.).

  • Le fichier filigrané sera au format PDF.
  • Vos fichiers ne quittent jamais votre appareil : tout le traitement est réalisé dans votre navigateur, sans serveur. La page fonctionne même hors connexion une fois chargée.
  • Le filigrane est incrusté dans l’image de chaque page : il ne peut pas être retiré en éditant le PDF.
Sélectionner des fichiers : Formats supportés : jpg, png, heic, pdf. Plusieurs fichiers = un seul PDF.
